# Componente Angular de respuesta

Componente standalone de referencia para integrarlo en Angular 20.

Antes de usarlo:
- Configurar `provideHttpClient()` en la aplicación.
- Crear ruta `/autorizar/:token`.
- Conectar el backend real y completar `AuthorizationResponseService`.
- Revisar la política de privacidad y autenticación adicional.
- El componente es una base de UI; no representa una integración terminada.
